## Network Forensics Lab

This repository contains hands-on investigations focused on network traffic analysis, malware detection and incident investigation using PCAP files.

The goal is to simulate real-world Security Operations Center (SOC) scenarios, identifying malicious activity, extracting indicators of compromise (IOCs) and building structured incident reports.

---

### Objectives

- Analyze network traffic using Wireshark
- Investigate malware infections through PCAP data
- Identify Indicators of Compromise (IOCs)
- Reconstruct attack timelines
- Develop incident analysis and reporting skills

---

### Tools & Technologies

- Wireshark
- PCAP (Packet Capture Analysis)
- Network Protocol Analysis (DNS, HTTP, TCP)
- Threat analysis techniques
